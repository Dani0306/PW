# Bitácora de prompts

Entregable — Semana 3.

Acá anoto los prompts que usé para pedirle ayuda a la IA con este proyecto,
y qué hice con cada respuesta: si la usé tal cual (aceptado), si la cambié
antes de usarla (corregido), o si no la usé (descartado).

## Aceptados

**Prompt:** "Ayudame a armar una página HTML simple para un blog, con un
encabezado, algunas entradas y un pie de página."
**Qué hice:** usé la estructura que me dio casi tal cual, porque era clara
y entendía cada parte.

**Prompt:** "Explicame para qué sirve el archivo .gitignore y dame un
ejemplo simple para un proyecto de HTML y CSS."
**Qué hice:** usé el ejemplo que me dio, agregando lo que ya sabía que
necesitaba (como `.DS_Store`).

## Corregido

**Prompt:** "Dame ideas de diseño para la página."
**Qué hice:** la primera propuesta usaba muchos colores, animaciones y una
fuente que había que descargar de internet. Le pedí que lo simplificara
porque yo recién estoy empezando, y me quedé con una versión con solo dos
colores y la fuente que ya viene en la computadora.

## Descartado

**Prompt:** "Agregá JavaScript para que la página tenga botones interactivos
para filtrar las entradas."
**Qué hice:** no lo usé. El entregable de la semana 1 pedía una página
estática funcionando en local, y agregar JavaScript en esta etapa me
pareció más complicado de lo que necesitaba por ahora.
