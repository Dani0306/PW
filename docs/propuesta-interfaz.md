# Propuesta de interfaz (con ayuda de IA)

Entregable — Semana 4.

Le pedí ideas de diseño a una IA para esta página y elegí las que mejor
me quedaban, simplificando lo que era demasiado para el nivel en el que
estoy.

## Colores que elegí

- **Verde oscuro (`#4a7c59`)** para el encabezado y los títulos. Se ve
  prolijo y no cansa la vista.
- **Gris clarito (`#f5f5f5`)** de fondo para toda la página.
- **Blanco** para las tarjetas de cada entrada, para que resalten sobre
  el fondo gris.

## Cómo está organizada la página

```
┌────────────────────────────┐
│  Encabezado (título verde) │
├────────────────────────────┤
│  Entrada 1 (tarjeta blanca)│
│  Entrada 2 (tarjeta blanca)│
│  Entrada 3 (tarjeta blanca)│
├────────────────────────────┤
│  Pie de página             │
└────────────────────────────┘
```

Cada entrada del blog es una tarjeta separada con un título, una fecha
y el texto. Es un diseño simple a propósito, para poder entender bien
cada línea de CSS que escribí.

## Qué cambié de lo que propuso la IA

La IA me sugirió usar una fuente decorativa que había que descargar de
internet, colores más oscuros de fondo, y animaciones cuando cargaba la
página. Decidí no usar nada de eso todavía: preferí una fuente que ya
viene instalada en cualquier computadora y sin animaciones, para que el
proyecto sea simple y funcione siempre, sin depender de internet para
verse bien.
