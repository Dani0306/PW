Acá voy anotando lo que aprendo semana a semana en el curso.

Semana 1: Instalando mis herramientas

3 de agosto de 2026

Esta semana instalé VS Code y Visual Studio 2026 Community para comparar los dos. Al principio no sabía bien la diferencia, pero ahora entiendo que VS Code es más liviano y Visual Studio trae más cosas ya integradas. Elegí VS Code para este proyecto porque es más simple para empezar.

Lo más importante que aprendí: no hace falta instalar mil extensiones el primer día. Con el editor y poco más ya podía ver mi página funcionando en el navegador.

Semana 2: Git y GitHub

10 de agosto de 2026

Aprendí a usar Git para guardar los cambios de mi proyecto paso a paso, y a subirlo a GitHub. Al principio me costó entender qué era un "commit", pero ahora lo pienso como una foto del proyecto en un momento dado, con una nota explicando qué cambié.

También aprendí para qué sirve el archivo .gitignore: para decirle a Git qué archivos NO tiene que guardar (como archivos temporales del editor).

Semanas 3 y 4: Programando con ayuda de IA

24 de agosto de 2026

Usé una IA para ayudarme a armar esta página y a pensar los colores. No todo lo que me propuso lo usé tal cual: algunas cosas las acepté, otras las cambié porque eran más complicadas de lo que necesitaba, y algunas directamente no las usé.

Anoté todo eso en un archivo aparte para no olvidarme qué le pedí y qué hice con cada respuesta. Se puede ver en docs/bitacora-prompts.md.
